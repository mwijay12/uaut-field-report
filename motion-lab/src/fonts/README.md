# Fonts

Latin subsets of three variable fonts, copied from the Fontsource packages so the site makes no third-party font requests.

| File | Family | Axes | Licence |
|---|---|---|---|
| `fraunces-latin-opsz-normal.woff2` | Fraunces | weight, optical size | SIL OFL 1.1 |
| `fraunces-latin-opsz-italic.woff2` | Fraunces Italic | weight, optical size | SIL OFL 1.1 |
| `inter-latin-wght-normal.woff2` | Inter | weight | SIL OFL 1.1 |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono | weight | SIL OFL 1.1 |

Sources: `@fontsource-variable/fraunces`, `@fontsource-variable/inter`, `@fontsource-variable/jetbrains-mono`.

The Latin subset has no right arrow or star glyphs. Use inline SVG for those so they do not fall back to a system font.
